Keep existing `BANNED_AI_PHRASES` for `v1.x` compatibility and add `BANNED_AI_V2_CONCLUSION_PHRASES` for `v2.0` reports (`подводя итог, можно заключить`, `резюмируя вышеизложенное`, `индивидуальный подход к каждому пациенту`, `выбор метода зависит от индивидуальных особенностей`, `каждый метод имеет свои преимущества и недостатки`, `не существует универсального метода`, `заслуживает особого внимания`, `в заключение следует отметить`, `в контексте современной медицины`, `является методом выбора для всех`).
4. Implement `check_humanizer_v2_structure(text: str, *, mode: str = "dissertation", schema_version: str = "2.0", max_bold_lead_ratio: float = 0.35) -> dict[str, Any]`:
   - Strip `## Список литературы` (and everything after it), fenced code blocks (` ```...``` `), and Markdown tables (`|...|`) before structural analysis.
   - Count:
     - `bold_lead_bullets`: list lines matching `^\s*[-*+]\s+\*\*[^*]{2,120}\*\*(?:\s*[:—–-])?`
     - `total_bullets`: all list lines matching `^\s*(?:[-*+]|\d+\.)\s+\S`
     - `prose_paragraphs`: contiguous narrative paragraph blocks (lines not starting with heading `#`, list bullet, table `|`, blockquote `>`, horizontal rule `---`) whose stripped length is `>= 120` characters.
     - `bold_lead_bullet_ratio`: `round(bold_lead_bullets / max(1, bold_lead_bullets + prose_paragraphs), 4)`.
     - `max_consecutive_bold_bullets`: longest uninterrupted run of bold-lead bullet lines.
   - Detect **mechanical pigeonhole routing** (`pigeonhole_matches`):
     - Extract the final analytical section / conclusion (last `## ` heading matching `заключ|вывод|тактик|алгоритм|резюме|стратег|итог|рекомендац` or final 25% of body text before bibliography).
     - Flag if 3+ consecutive lines/sentences mechanically map disjoint stages/groups to mutually exclusive treatments (e.g., patterns like `(?:для|при)\s+(?:стади[ия]|степен[иь]|групп[еы]|тип[еа]|вариант[еа]|форм[еы])\s*(?:I|II|III|1|2|3|легк|средн|тяжел|ранн|поздн)[^.\n]{0,60}(?:подходит|показан|рекомендуется|выбирают|метод\s+выбора|—)` occurring `>= 3` times in close proximity, OR explicit slot-matching sentences `"подходит для 1"` / `"для первой группы"` + `"для второй группы"` + `"для третьей группы"` without competing workhorse nuance signals).
   - Detect **non-linear clinical decision nuance signals** (`has_overlapping_nuance_signals`) in the final/tactical section: matches terms indicating overlapping/workhorse methods and practical trade-offs (`перекрыва`, `сквозн`, `конкурир`, `нюанс`, `компромисс`, `опыт хирург`, `крив\w+\s+обучен`, `оснащен`, `доступност`, `рубец`, `предпочтен\w*\s+пациент`, `оба метода`, `равноценн`, `альтернатив`).
   - Detect **treatment complications analysis presence** (`has_complications_analysis`) in body text: checks presence of a complications/safety heading or structured discussion mentioning `осложнен` AND (`clavien` or `ctcae` or `ятроген` or `транзиторн` or `профилактик` or `обратим`).
   - Check `v2_banned_phrases` (`BANNED_AI_PHRASES + BANNED_AI_V2_CONCLUSION_PHRASES`).
   - Populate `errors: list[str]` and `warnings: list[str]`:
     - When `schema_version == "2.0"`:
       - Any `BANNED_AI_PHRASES` or `BANNED_AI_V2_CONCLUSION_PHRASES` -> `errors`.
       - In `dissertation` mode: `bold_lead_bullet_ratio > max_bold_lead_ratio` -> `errors`; `max_consecutive_bold_bullets > 6` -> `warnings`.
       - In `dissertation` or `summary` mode: `pigeonhole_matches` detected -> `errors`; missing `has_overlapping_nuance_signals` in final/tactical chapter -> `errors`; missing `has_complications_analysis` -> `errors`.
     - When `schema_version != "2.0"` (`v1.x` compatibility): only legacy `BANNED_AI_PHRASES` go to `errors`; structural `v2.0` findings go to `warnings` (non-blocking).
   - Return structured dict `{passed, schema_version, mode, bold_lead_bullets, total_bullets, prose_paragraphs, bold_lead_bullet_ratio, max_consecutive_bold_bullets, pigeonhole_matches, has_overlapping_nuance_signals, has_complications_analysis, banned_phrases_found, errors, warnings}`.
5. Update `verify_all_reports(nosology_id: str = "prom", *, schema_version: str = "auto", write_outputs: bool = True, base_dir: Path | None = None) -> dict[str, Any]`:
   - Open SQLite via `_connect_sqlite_readonly(db_path)` (never mutating `literature.db`).
   - When `write_outputs=False` (`--read-only`), do NOT write `@PMID:` replacements, `.docx` files, or `verification_audit.md`.
   - Resolve `effective_version`: `"2.0"` if `schema_version == "v2"` or (`schema_version == "auto"` and `str(kb_data.get("schema_version", "")) == "2.0"`), else `"1.x"`.
   - Run `check_humanizer_v2_structure()` on `dissertation_report.md` (`mode="dissertation"`) and `executive_summary.md` (`mode="summary"`), and when `effective_version == "2.0"`, assert `res["passed"]` (zero structural errors) AND assert `validate_kb_v2(kb_data) == []` (verifying `frequent_complications`, `rare_critical_red_flags`, and `clinical_decision_nuances`).
   - Include structural linter metrics (`bold_lead_bullet_ratio`, `schema_version`, `humanizer_v2_status`) in `verification_audit.md` when `write_outputs=True`.
   - Update CLI flags in `main()`: add `--schema-version` (`choices=["auto", "v1", "v2"]`, default `"auto"`) and `--read-only` (`action="store_true"`).
