# Requirements: Information Searcher (Контрактура Дюпюитрена 2016–2026)

**Defined:** 2026-11-04
**Core Value:** Доказательный, верифицируемый по PMID/DOI синтез клинической и фундаментальной литературы за 10 лет без галлюцинаций, канцелярита и ИИ-штампов, опирающийся на структурированную базу извлеченных данных.

## v1 Requirements

### Сбор и PRISMA-скрининг (HARV)

- [ ] **HARV-01**: Универсальный сборщик (`src/harvester.py`), принимающий `configs/<nosology>.yaml` и выгружающий статьи за 2016–2026 гг. из PubMed, Europe PMC, OpenAlex и клинических исследований из ClinicalTrials.gov.
- [ ] **HARV-02**: Дедупликация по DOI / PMID / PMCID / заголовку и сохранение единого реестра в `data/<nosology>/literature.db`.
- [ ] **HARV-03**: Автоматическая стратификация статей по уровням доказательности (`Tier 1`: метаанализы/РКИ/гайдлайны; `Tier 2`: когорты/GWAS/scRNA-seq; `Tier 3`: серии/in vitro/обзоры; `Tier 4`: кейсы/письма) и разметка по 5 тематическим кластерам (`src/triage.py`).
- [ ] **HARV-04**: Автоматическая выгрузка открытых полнотекстовых XML из Europe PMC для работ `Tier 1–2` и генерация PRISMA-отчета по корпусу (`reports/dupuytren/prisma_stats.md`).

### Роевая структурированная экстракция (EXTR)

- [ ] **EXTR-01**: Экстракция по кластеру «Этиология, эпидемиология и генетика» (GWAS-локусы, сигнальный путь Wnt, популяционная распространенность, диабет, алкоголь, курение, ручной труд и вибрация, диатез Дюпюитрена) в таблицу `extracted_mechanisms`.
- [ ] **EXTR-02**: Экстракция по кластеру «Молекулярный и клеточный патогенез» (биология миофибробластов, TGF-β1/Smad, механотрансдукция YAP/TAZ, иммунное микроокружение/TNF/макрофаги, ремоделирование коллагена III/I, данные scRNA-seq) в таблицу `extracted_mechanisms`.
- [ ] **EXTR-03**: Экстракция по кластеру «Консервативные и малоинвазивные методы» (игольная апоневротомия PNF, коллагеназа C. histolyticum CCH, анти-TNF адалимумаб, лучевая терапия, УВТ, ортезирование) в таблицу `extracted_clinical_evidence`.
- [ ] **EXTR-04**: Экстракция по кластеру «Хирургическое лечение, осложнения и отдаленные результаты» (ограниченная/селективная фасциэктомия, дермофасциэктомия, WALANT, липографтинг, кожная пластика, динамика рецидивов на 1–3–5–10 годах раздельно для ПФС и ПМФС) в таблицу `extracted_clinical_evidence`.

### Генерация отчетов в 3 режимах с де-ИИзацией (SYNT)

- [ ] **SYNT-01**: Написание полного отчета диссертационного уровня (`reports/dupuytren/dissertation_report.md`) со строгим соблюдением правил `ru-medical-humanizer`, сводными таблицами и верифицированными ссылками `[PMID: ...]`.
- [ ] **SYNT-02**: Генерация краткого аналитического содержания (`reports/dupuytren/executive_summary.md`) с ключевыми выводами за 10 лет и сравнительными матрицами.
- [ ] **SYNT-03**: Формирование модульной внутренней базы знаний (`reports/dupuytren/knowledge_base/`) по мишеням, факторам риска, методам лечения и ключевым РКИ.

### Веб-интерфейс и универсальный запуск (UI)

- [ ] **UI-01**: Веб-приложение (`app.py` на Streamlit) с переключателем трех вариантов отчета, интерактивной PRISMA-воронкой, фильтрацией всех статей базы, таблицами сравнения методов лечения и выбором нозологии из `configs/`.

## v2 Requirements

- **AUTO-01**: Автоматический мониторинг новых публикаций по расписанию (Living Systematic Review).
- **EXPORT-01**: Прямая компиляция диссертационного отчета в ГОСТ-оформленный DOCX и PDF.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Парсинг пиратских баз (Sci-Hub и др.) | Работа ведется строго через официальные API (NCBI, Europe PMC, OpenAlex, ClinicalTrials.gov) с соблюдением лицензий |
| Обычный векторный чат без предварительной табличной экстракции | Не дает точной сводной статистики по частоте рецидивов и осложнений |
