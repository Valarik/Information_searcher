# Information_searcher — Универсальная платформа доказательного медицинского синтеза (2016–2026)

Автономная многофазная исследовательская система для программного сбора литературы из мировых биомедицинских баз (`PubMed`, `Europe PMC`, `OpenAlex`, `ClinicalTrials.gov`), автоматизированного PRISMA-триажа, кластерной экстракции в реляционную базу данных `SQLite` и генерации строго верифицированных клинических отчётов в 3 режимах с интерактивным веб-интерфейсом на `Streamlit`.

Референсная нозология первого выпуска: **Контрактура Дюпюитрена (ладонный фиброматоз, МКБ-10: `M72.0` / МКБ-11: `FB51.0`)**.

---

## 1. Быстрый запуск интерактивного веб-приложения (`UI-01`)

Требуется установленный менеджер пакетов [`uv`](https://docs.astral.sh/uv/) (все зависимости `streamlit`, `pandas`, `plotly`, `markdown`, `pyyaml` подтягиваются автоматически через встроенный заголовок `PEP 723` в `app.py`):

```powershell
$env:PATH = "$HOME\.local\bin;" + $env:PATH
uv run streamlit run app.py
```

Для запуска автоматического безголового самотестирования всех 4 вкладок, схемы `kb_index.json`, запросов `SQLite` и экспортов `.html` / `.csv`:

```powershell
$env:PATH = "$HOME\.local\bin;" + $env:PATH
uv run app.py --self-test
```

## 2. Унифицированная нозологически-независимая архитектура (`D-01`–`D-03`)

Веб-приложение `app.py` и адаптер [`src/universal_schema.py`](src/universal_schema.py) спроектированы универсально для **любой нозологии**, подключённой через `configs/<nosology_id>.yaml`:

1. **Вкладка 1 — Аналитические отчёты (3 режима):**
   - **Режим А (`SYNT-01`):** академическая диссертационная монография ([`reports/dupuytren/dissertation_report.md`](reports/dupuytren/dissertation_report.md), 4 главы + Заключение + библиография из 87 источников `[1]..[87]`) с навигацией по главам и подсветкой искомых терминов;
   - **Режим Б (`SYNT-02`):** краткий клинический отчёт ([`reports/dupuytren/executive_summary.md`](reports/dupuytren/executive_summary.md)) со сводными алгоритмами выбора тактики;
   - **Режим В (`SYNT-03`):** модульная база знаний ([`reports/dupuytren/knowledge_base/`](reports/dupuytren/knowledge_base/)) из 5 тематических модулей;
   - **Экспорт (`D-03`):** скачивание любого отчёта или главы в формате `.md` и в виде самодостаточного **печатного HTML-документа** (готового к сохранению в PDF через браузер `Ctrl+P` или открытию в MS Word).
2. **Вкладка 2 — Унифицированная клиническая аналитика:**
   - **2.1. Классификация стадий тяжести и анатомические/клинические подтипы:** сопоставление популяционной доли стадий с долей пациентов в хирургическом потоке и ранжирование локализаций;
   - **2.2. Этиология, факторы риска и фазы патогенеза:** факторы риска (`↑`) и протективные модификаторы (`↓`) с силой эффекта (`OR/HR/h²`) и пошаговыми фазами патогенеза с указанием терапевтических окон;
   - **2.3. Естественное течение против методик лечения (Первичная эффективность, Ремиссия, Истинный рецидив и Процедив):**
     - **Естественное развитие (`Natural History`)** без инвазивного вмешательства;
     - **Первичная эффективность и 5-летняя ремиссия (`Primary Efficacy & Remission`)**;
     - **Истинный рецидив (`True Recurrence / Relapse`)** в леченой зоне на горизонтах `1–2`, `3`, `5` и `10 лет`;
     - **Процедив (`Disease Progression / Extension`)** — продолженный рост или распространение заболевания на соседние анатомические зоны;
   - **2.4. Бок-о-бок сравнение методик (`Side-by-Side Comparator`) + доказательства из SQLite:** параллельное сопоставление любых 2–4 методик (плюсы, минусы, ремиссия, рецидив, процедив, осложнения, реабилитация) и фильтрация подтверждающих строк из `extracted_clinical_evidence`.
3. **Вкладка 3 — База литературы и PRISMA-навигатор (`SQLite Explorer`):**
   - Интерактивный поиск, фильтрация и выгрузка в `.csv` (`UTF-8 with BOM` для Excel) по 4 таблицам [`data/dupuytren/literature.db`](data/dupuytren/literature.db):
     - `articles` (**2 209** уникальных работ, **1 775** включённых после PRISMA-скрининга, **233** полнотекстовых XML);
     - `extracted_clinical_evidence` (**1 213** структурированных клинических записей);
     - `extracted_mechanisms` (**1 062** патогенетические и генетические записи);
     - `clinical_trials` (**80** протоколов `ClinicalTrials.gov`).
4. **Вкладка 4 — Аудит верификации и Конфигуратор новых нозологий:**
   - Сертификат [`reports/dupuytren/verification_audit.md`](reports/dupuytren/verification_audit.md) (`0` неподтверждённых идентификаторов `PMID/PMCID/DOI/NCT`, `0` ИИ-штампов);
   - Генератор конфигурационных файлов `configs/<new_nosology>.yaml` прямо из интерфейса.

## 3. Структура проекта и команды 4-фазного пайплайна

```text
├── app.py                          # Универсальное интерактивное веб-приложение Streamlit (Фаза 4)
├── configs/
│   └── dupuytren.yaml              # Конфигурация нозологии (запросы, МКБ-10/11, MeSH)
├── src/
│   ├── schema.py                   # Схема таблиц SQLite
│   ├── harvester.py                # Фаза 1: Сбор PubMed, Europe PMC, OpenAlex, ClinicalTrials.gov
│   ├── triage.py                   # Фаза 1: Дедупликация, PRISMA-триаж, загрузка JATS XML
│   ├── extractor_common.py         # Фаза 2: Ядро кластерной экстракции
│   ├── extract_cluster_1..4.py     # Фаза 2: Экстракция по 4 аналитическим кластерам
│   ├── verify_reports.py           # Фаза 3: Компиляция библиографии и Zero-Tolerance аудит
│   └── universal_schema.py         # Фаза 4: Универсальный адаптер нозологий и HTML/CSV экспорт
├── data/dupuytren/
│   ├── literature.db               # Реляционная база SQLite (1775 статей, 1213 клин., 1062 мех., 80 РКИ)
│   └── extractions/                # 4 кластерных аналитических досье
└── reports/dupuytren/
    ├── dissertation_report.md      # Режим А: Диссертационная монография (128 КБ)
    ├── executive_summary.md        # Режим Б: Краткий клинический отчёт (29 КБ)
    ├── prisma_stats.md             # Сводка отбора PRISMA
    ├── verification_audit.md       # Сертификат верификации ссылок и стиля
    └── knowledge_base/             # Режим В: 5 модулей базы знаний + kb_index.json
```

### Команды запуска пайплайна для любой нозологии:

```powershell
$env:PATH = "$HOME\.local\bin;" + $env:PATH

# 1. Сбор литературы и PRISMA-триаж
uv run src/harvester.py --config configs/dupuytren.yaml
uv run src/triage.py --config configs/dupuytren.yaml

# 2. Верификация ссылок, компиляция библиографии и проверка универсальной схемы
uv run src/verify_reports.py --compile-bibliography --verify
uv run src/universal_schema.py --verify

# 3. Самотестирование и запуск веб-интерфейса
uv run app.py --self-test
uv run streamlit run app.py
```
